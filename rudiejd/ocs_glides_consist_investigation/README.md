# ocs_glides_consist_investigation

Report by the Transit Data team analyzing the number of vehicle location pings that we get for the green line by length of the train in each ping.


## Dependencies
[uv](https://docs.astral.sh/uv/). 

You can install this from the notebooks repository using `mise`, or install on your own.

## Usage
1. To edit the notebook, run `uv run marimo edit notebook.py`
2. This will install all of the necessary dependencies, and create a Python virtual environment
3. You will be presented with a prompt to edit the notebook in your browser. Click on the provided URL
